# กระดานคัดหุ้น SET & DR — อัปเดตราคาอัตโนมัติทุกชั่วโมง

## วิธีติดตั้ง (ครั้งเดียว ~10 นาที ฟรีทั้งหมด)

1. สมัคร/ล็อกอิน GitHub → กด **New repository** ตั้งชื่อ เช่น `set-dr-dashboard` (เลือก Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo (ลากวางผ่านหน้าเว็บได้ — ต้องคงโครงสร้างโฟลเดอร์ `docs/`, `scripts/`, `.github/workflows/`)
3. ไปที่ **Settings → Pages** → Source เลือก `Deploy from a branch` → Branch `main` / โฟลเดอร์ `/docs` → Save
4. ไปที่แท็บ **Actions** → กด enable workflow → เลือก "Update prices hourly" → กด **Run workflow** หนึ่งครั้งเพื่อดึงราคารอบแรก
5. เสร็จแล้ว! ลิงก์ของคุณคือ `https://<ชื่อผู้ใช้>.github.io/set-dr-dashboard/`
   เปิดจากมือถือได้เลย และกด "Add to Home Screen" ให้เหมือนแอปได้

## ระบบทำงานยังไง
- GitHub Actions รัน `scripts/update_prices.py` ทุกชั่วโมง (นาทีที่ 15)
- สคริปต์ดึงราคาล่าสุดจาก Yahoo Finance (สัญลักษณ์ .BK) → เขียนลง `docs/data.json`
- หน้าเว็บอ่าน `data.json` มาแสดงราคา + คำนวณสถานะเทียบโซนซื้อ/TP/SL อัตโนมัติ
- เปิดหน้าค้างไว้ หน้าเว็บจะรีเฟรชข้อมูลเองทุก 15 นาที

## แก้รายชื่อหุ้น
- เพิ่ม/ลบหุ้น: แก้ทั้ง `SYMBOLS` ใน `scripts/update_prices.py` และ `DATA` ใน `docs/index.html`

## หมายเหตุ
- ราคาจาก Yahoo Finance อาจดีเลย์ ~15 นาที และ cron ของ GitHub อาจคลาดเคลื่อนได้บ้างในชั่วโมงเร่งด่วน
- เป้าหมาย/SL เป็นข้อมูลจากบทวิเคราะห์ ณ ต้นเดือน ส.ค. 2569 — ควรอัปเดตเองเมื่อโบรกออกบทวิเคราะห์ใหม่
- ใช้เพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน
